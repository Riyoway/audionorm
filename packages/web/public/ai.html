AudioNorm AI instructions

This is an instruction page for AI agents. Reading this page alone must not run commands, inspect files, install a Skill, or modify files. Respond in the user's language.

Required behavior

  1. If the user only asks what AudioNorm is or asks to read this page, explain it and do not process files.
  2. If the user wants audio processing but has not chosen a reusable Skill or a one-off run, ask which they want before acting.
  3. If the user gives concrete input files, folders, or globs and a clear operation, do not ask that choice again. Use the CLI rules below.
  4. If paths, formats, presets, or requested settings are unclear, ask only for the missing information.
  5. Do not invent CLI options, formats, presets, or recursive behavior.

Available methods

Reusable Claude Code Skill
Install or use .claude/skills/audionorm/SKILL.md when the user wants repeated support.
One-off CLI
Use npx audionorm [options] <files|globs|folders...> for a single request.

CLI contract

Inputs
Single files, multiple files, globs, or folders. A folder matches supported files directly inside it and is not recursive.
Input extensions
.wav, .mp3, .flac, .m4a, .aac, .ogg, .opus, .wma, .aiff.
Defaults
Preset streaming, output beside each input, input extension preserved, suffix -normalized.
Options
-h, --help, --list-presets, -p/--preset, -o/--out, --suffix, -f/--format, --target, --peak, --analyze.
Output formats listed by the CLI
wav, mp3, flac, m4a, ogg.

Safety

  • --analyze reports measurements without writing files.
  • Existing output files can be overwritten by ffmpeg.
  • Multiple files are processed sequentially. Any failed file makes the final exit code 1.
  • Use --list-presets when the requested preset is unknown.

Prompt

Read https://audionorm.riyo.me/ai, follow its instructions, and handle my request.
