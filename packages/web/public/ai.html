Use AudioNorm safely from an AI agent.

This page describes the real audionorm CLI and the project Skill. It is documentation only. Opening or reading this page never runs a command and never changes a file.

Before doing anything

If the user's goal is unclear, ask whether they want the reusable Claude Code Skill or a one-off npx run. If the user already gave concrete files and a clear audio operation, do not ask that extra choice. Ask only for missing paths or settings. Respond in the user's language.

What AudioNorm does

AudioNorm normalizes loudness or peak level locally. The CLI accepts one or more audio files, globs, or folders and processes matching files sequentially.

Two ways to use it

Reusable Skill

Install or keep this repository Skill at .claude/skills/audionorm/SKILL.md when the user wants repeated Claude Code use.

One-off npx

Run npx audionorm for a single request when no reusable Skill is needed.

CLI contract

npx audionorm [options] <files|globs|folders...>
Inputs
Single files, multiple files, globs, or folders. Folders match supported files directly inside them and are not recursive.
Input extensions
.wav, .mp3, .flac, .m4a, .aac, .ogg, .opus, .wma, .aiff.
Defaults
Preset streaming, output beside each input, input extension preserved, suffix -normalized.
Options
-h/--help, --list-presets, -p/--preset, -o/--out, --suffix, -f/--format, --target, --peak, --analyze.
Output formats in CLI help
wav, mp3, flac, m4a, ogg. Do not invent additional formats.

Important behavior

  • --target overrides LUFS target.
  • --peak overrides peak target.
  • --analyze measures and reports without writing files.
  • Existing output files can be overwritten by ffmpeg.
  • Multiple files run sequentially. Any failed file makes the final exit code 1.

Examples

npx audionorm track.wav
npx audionorm -p podcast "*.mp3"
npx audionorm -p sfx ./sounds -o ./sounds-fixed
npx audionorm --analyze track.wav
npx audionorm --target -12 song.flac -f wav
